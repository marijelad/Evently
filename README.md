 Evently - Event Discovery & Ticketing UI

Built with HTML, CSS, and vanilla JavaScript.

 Highlights
- 12 fictional event detail pages with custom local SVG poster artwork
- Search, category filtering, price/date sorting
- Saved events using localStorage
- Responsive navigation and light/dark theme
- Venue directory and detail pages
- Organizer landing page, dashboard concept, event creation form
- Demo ticket checkout and confirmation flow
- FAQ accordion, journal, contact, legal and 404 pages
- No external image dependencies and no API keys



> Portfolio demo only. Event listings, venues, pricing, organizers, and checkout are fictionalized. No real tickets or payments are processed.
