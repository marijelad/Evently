Good events make cities feel smaller.

Evently is a fictional event discovery product created as a polished front-end portfolio project.

Discovery without the noise.

The interface is designed around fast scanning, strong imagery, transparent event details, and intentional curation.

Built as a real product system.

Reusable cards, filters, favorites, responsive layouts, local state, checkout flows, venue pages, and organizer tools all work together.

Design principles

Clear first

Every screen answers where, when, what, and how much before decoration gets in the way.

Energetic, not noisy

Color and motion support the mood while the dark UI keeps content easy to scan.

Responsive by default

Layouts and controls adapt to phones, tablets, and desktop screens without losing hierarchy.
